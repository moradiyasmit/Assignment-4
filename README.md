# 🧺 Laundry Service Website

This project uses EmailJS for booking notifications. To run locally, simply open index.html. Credentials used: Service ID service_smit12, Public Key 2n1Vv08rGpWwewE6G.".

Users can select laundry services, add them to a cart, view total amount, and book a service. Booking details are sent via Email using EmailJS.

---

# Features

* Add services to cart
* Total price calculation
* Booking form with validation
* Email sending using EmailJS
* LocalStorage used to save cart data
* Responsive design

---

# Technologies Used

* HTML
* CSS
* JavaScript
* EmailJS

---

# How It Works

1. User selects services
2. Services are added to cart
3. Total amount is calculated automatically
4. User fills booking form
5. Data (name, email, phone, services, total) is sent via EmailJS

---

#  Email Data Sent

* Name
* Email
* Phone Number
* Selected Services
* Total Amount

---

# Validation

* Email format validation
* Phone number (10 digits only)
